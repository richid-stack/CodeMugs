Connect your application. Give it a path to improve.

CodeMugs brings your application’s code, runtime behavior, and engineering workflow together—then helps turn what it learns into verified improvements.

Connect through our SDKs, OpenTelemetry, APIs, and integrations. CodeMugs builds context across your stack, investigates issues with evidence, and prepares changes your team can review.

Your application is more than its source code.

The clues that explain a problem are spread across your repositories, services, telemetry, deployments, databases, and customer feedback.

CodeMugs connects those signals to create a living understanding of how your application is built and how it behaves—so your team and its engineering agents can work from the same context.

Connection methods

Fifteen ways in. Pick the one that fits.

Scroll. Each method slides over the last.

SDK

JavaScript / TypeScript SDK

Instrument frontend and Node.js applications to capture application events, errors and performance signals.

npm i @codemugs/sdk
import { init } from "@codemugs/sdk"
init({ key: CM_KEY })
SDK

Python SDK

Connect Python applications and backend services with structured telemetry and custom application events.

pip install codemugs
import codemugs
codemugs.init(key=CM_KEY)
REST

REST API

Integrate any application or internal system through a flexible, standards-based API.

POST /v1/events
Authorization: Bearer cmk_…
{ "events": [{ "type": "deploy.finished", … }] }
Events

Webhooks

Stream relevant application and infrastructure events into CodeMugs as they happen.

POST https://you.dev/hooks/codemugs
X-CodeMugs-Signature: sha256=…
{ "event": "finding.created" }
Telemetry

OpenTelemetry

Bring existing logs, metrics and distributed traces into CodeMugs without depending exclusively on proprietary instrumentation.

OTEL_SERVICE_NAME=checkout
OTEL_EXPORTER_OTLP_ENDPOINT=\
  https://otlp.codemugs.io
Terminal

CLI

Connect, configure and manage applications directly from the developer’s terminal.

$ codemugs login
$ codemugs connect ./my-app
✓ 3 services detected
Source control

GitHub App

Give CodeMugs authorised access to repositories, commits, pull requests, issues and development activity.

Install → choose repositories
✓ read: code, PRs, commits
✓ write: pull requests only
Source control

GitLab & Bitbucket

Connect alternative source-control environments and bring their development activity into the same intelligence layer.

gitlab.com/acme/api       ✓ linked
bitbucket.org/acme/web    ✓ linked
Agents

Infrastructure agents and collectors

Collect authorised runtime and infrastructure signals from customer environments.

helm install cm-agent codemugs/agent
✓ collector running
✓ host signals flowing
Data

Database connectors

Connect database metadata, health and performance information to understand the data layer.

postgres://readonly@db/orders
✓ schema mapped
✓ read-only role verified
Cloud

Cloud integrations

Bring cloud resources, deployment information and operational signals into application context.

role: codemugs-readonly
scope: resources, deployments
✓ account connected
Runtime

Docker & Kubernetes

Understand containerised applications, workloads, services and orchestration environments.

kubectl apply -f codemugs.yaml
✓ workloads discovered
✓ deploy history synced
AI agents

MCP server

Allow compatible AI agents and external tools to interact with CodeMugs through a standardised tool interface.

{ "mcpServers": { "codemugs": {
    "url": "https://mcp.codemugs.io"
} } }
Frontend

Browser instrumentation

Capture permitted frontend performance and behavioural signals to help identify problems affecting real users.

<script async data-key="cm_pub_…"
  src="https://cdn.codemugs.io/web.js">
</script>
Extensible

Custom connector SDK

Build and contribute integrations for specialised platforms and internal systems.

defineConnector({
  name: "my-tool",
  pull: async () => events
})
