# Brand assets

| File                 | Use                                                                                                                    |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `logo-on-light.svg`  | The logo with its name, in near-black, for light backgrounds. The repository README uses it in light mode              |
| `logo-on-dark.svg`   | The same, in cream, for dark backgrounds. The repository README uses it in dark mode                                   |
| `logo-mark.svg`      | The mark alone on a dark rounded tile: an avatar, an app icon or a favicon                                             |
| `social-preview.png` | 1280 × 640. The image that appears when the repository's link is shared. Upload it under **Settings → Social preview** |

## The mark

A five by five grid of rounded squares with the four corners cut off, in which seven lit squares make a smiling face. The dim squares are the same colour at 18% opacity.

| Colour      | Value     |
| ----------- | --------- |
| Ink         | `#101114` |
| Cream       | `#F4F1EA` |
| Site ground | `#050507` |

The name is set in Space Grotesk Bold with tracking of -0.03 em, converted to outlines so that the files need no font. Space Grotesk is licensed under the SIL Open Font License 1.1.

## Using it (suggested)

- Keep clear space around the mark of at least one dim square.
- Do not recolour, stretch or add effects.
- At about 20 pixels the dim squares blur into the tile. Use the tile at 32 pixels or more where you can.
- These files are the source of truth. There is no generator in the repository, so change them by hand.
